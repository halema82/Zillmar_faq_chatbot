# Zillmar FAQ Chatbot

A simple AI-powered chatbot that answers frequently asked questions using TF-IDF vectorization and cosine similarity.

## How it works
- Collects a list of FAQ question-answer pairs
- Converts questions into TF-IDF vectors using scikit-learn
- Matches the user's input question to the most similar FAQ using cosine similarity
- Returns the best-matching answer

## Built with
- Python
- scikit-learn

## Project context
Built as part of the CodeAlpha Artificial Intelligence Internship (Task 2: Chatbot for FAQs).
